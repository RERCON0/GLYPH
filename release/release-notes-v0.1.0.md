# GLYPH 0.1.0

Первый публичный релиз. Один переносимый `GLYPH.exe` для Windows x64: без
установки, прав администратора, сети и фоновых служб.

## Что внутри

- Пять режимов: пароль, PIN, HEX, URL-safe и ключ Fernet.
- Случайность Windows CSPRNG через `getrandom`; выбор индексов rejection
  sampling без смещения, перемешивание Fisher–Yates. Отказ источника
  случайности прекращает генерацию — слабого запасного PRNG нет.
- Пароль 1–256 символов: минимум цифр, спецсимволы, исключение похожих
  `0 O o I l 1`, пресеты 16 / 32 / 64.
- Скрытые U+200B / U+200C / U+200D с просмотром `\u200B`-представления и
  реальным числом вставок; фильтр совместимости с Argon2 отключает их.
- Сеанс на 80 значений только в памяти: повторное копирование точного
  значения, маскировка, очистка, подсказки с длиной и энтропией.
- Автоочистка буфера через 30 секунд с проверкой владения и маркерами запрета
  истории/облачной синхронизации Windows. Чужая более поздняя копия не
  стирается.
- Тёмная и светлая темы, per-monitor DPI, русский интерфейс.
- Ни сетевых запросов, ни файлов настроек, ни истории на диске, ни логов.
  Ссылка `t.me/rercon` открывается в браузере только по явному клику.

## Требования

Windows 10/11 x64, OpenGL 2.1 или новее. MSVC CRT линкуется статически;
шрифт и иконка встроены.
